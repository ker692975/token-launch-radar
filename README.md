A token launch radar that ranks pre-token DeFi protocols by implied launch value from a frozen DefiLlama snapshot, with a sortable and filterable dashboard and a concrete farm plan for each protocol.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
